Memory & Storage Index — نسخة موقع عامة جاهزة للرفع إلى GitHub Pages

محتويات الحزمة:
- index.html: واجهة الموقع، لا تحتوي على ملفات تشغيل Mac أو تطبيقات تنفيذية.
- refresh.py: يجلب ملفات البيانات العامة من Pricify ويتحقق من بنيتها.
- .github/workflows/update-data.yml: يفحص البيانات يومياً عبر GitHub Actions ويحفظ التغييرات الجديدة فقط.
- data/status.json: حالة أولية؛ لا توجد بيانات أسعار منشورة حتى تشغيل أول تحديث.

النشر:
1) أنشئ حساباً في github.com إذا لم يكن لديك حساب.
2) أنشئ مستودعاً جديداً Public باسم memory-storage-index.
3) ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع إظهار الملفات المخفية حتى ترفع مجلد .github.
4) من Settings > Pages اختر Deploy from a branch، ثم Branch: main و Folder: / (root)، ثم Save.
5) من Actions شغّل Check Pricify data يدوياً لأول مرة. وافق على Actions إذا طلب GitHub ذلك.
6) انتظر اكتمال المهمة، ثم افتح رابط Pages الذي يظهر في Settings > Pages.

ملاحظات الخصوصية والأمان:
- الموقع عام؛ أي شخص لديه الرابط يستطيع مشاهدة البيانات والواجهة، والمستودع Public يعني أن ملفات المشروع نفسها عامة أيضاً.
- لا ترفع أي كلمات مرور أو مفاتيح API أو بيانات شخصية. هذه الحزمة لا تحتاجها.
- لا يوجد ملف .command ولا برنامج تنفيذي ولا حاجة إلى Terminal على الماك.
- لا يمكن اعتبار الحزمة منشورة قبل رفعها إلى حساب GitHub وتفعيل Pages.
